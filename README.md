# KTLanDrop

轻量级 Windows 电脑 ↔ iPad / 手机局域网互传与看漫工具（单文件 `.exe`，零第三方依赖）。

## 功能特性

- **文件双向互传**
  - **电脑 → iPad**：在 Safari 浏览器中浏览电脑共享目录、实时搜索、在线预览 PDF 或直接下载。
  - **iPad → 电脑**：从 iPad 相册或「文件」App 一键多选上传图片/文档到电脑接收目录。
- **📖 局域网看漫模式（v1.1.0 新增）**
  - **支持格式**：`.zip` / `.cbz` 漫画压缩包（免解压直接流式读取）以及图片文件夹（`.jpg` / `.png` / `.webp` / `.gif` / `.bmp`）。
  - **自动识别章节与自然排序**：打开某一话时自动扫描同级目录全部章节；直接点击漫画总文件夹也会自动进入第 1 话并加载目录。章节与图片均按自然数字排序（如 `第2话` 在 `第10话` 前）。
  - **双模式与触控手势**：
    - **条漫模式**：单指上下无缝连续滚动。
    - **页漫模式**：支持**左右滑动（Swipe）**、**点击左/右半屏翻页**、**日漫（右→左）/ 普通（左→右）** 方向切换，并后台预加载后续页面。
  - **目录抽屉 & 进度记忆**：轻点屏幕中央呼出/隐藏工具栏，支持章节目录抽屉跳转、页码滑块、「上一话 / 下一话」切换，并在 iPad 本地自动记住上次阅读进度。
- **💬 文字双向互传（选择性复制）**
  - 电脑端与网页端实时聊天框，支持各自一键复制，**不会自动覆盖电脑剪贴板**。
- **📷 自动识别局域网 IP + 二维码**
  - 自动过滤虚拟网卡（如 Clash/Meta、VMware、Hyper-V），生成二维码，iPad 相机一扫即开。
- **🔌 自适应端口 & 🛡️ 一键防火墙**
  - 端口被占用时自动顺延尝试可用端口，支持界面自定义端口；提供「一键放行防火墙」按钮（仅放行局域网 `LocalSubnet`）。
- **💾 记忆配置**
  - 自动将共享目录、接收目录与端口保存在 `%LocalAppData%\KTLanDrop\settings.ini`。

## 使用说明

1. **下载运行**：前往本仓库 [Releases](https://github.com/aktgod/KTLanDrop/releases) 下载 `KTLanDrop.exe` 双击运行。
2. **首次防火墙配置**：点击软件右上角 **「一键放行防火墙」**（仅需提权确认一次），之后日常使用不再弹窗。
3. **iPad 连接**：用 iPad 相机扫描软件界面的二维码，在 Safari 中打开。
   - *小技巧*：在 Safari 点「分享 → 添加到主屏幕」，从桌面图标打开即可全屏沉浸使用（隐藏浏览器地址栏）。
4. **看漫操作**：在文件列表找到漫画文件夹或 `.zip`/`.cbz`，点击右侧 **「📖 阅读」** 即可进入全屏阅读器。

## 本地编译

在任意 Windows 10/11 电脑上直接双击运行 `build.bat`（调用系统自带 `.NET Framework 4.x` 编译器 `csc.exe`，无需安装 Visual Studio），即可生成单文件 `KTLanDrop.exe`。
